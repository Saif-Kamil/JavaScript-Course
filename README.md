# Student Portfolio Project | Saif Kamil

A modern, responsive one-page portfolio website showcasing web development fundamentals including HTML5, CSS3, and JavaScript interactivity.

## 🚀 Project Overview
This project serves as a digital resume and gallery, featuring a clean "Navy & Cyan" aesthetic. It highlights foundational skills in front-end development, responsive design, and DOM manipulation.

## 🛠️ Built With
* **HTML5:** Semantic structure including `<nav>`, `<section>`, and `<form>`.
* **CSS3:** Custom Navy Blue theme, CSS Grid gallery, and smooth scroll animations.
* **JavaScript:** Interactive Lightbox modal, automated slideshow logic, and contact form toggles.

## 📋 Key Features
* **Interactive Lightbox:** Click any gallery image to view it in a high-resolution modal.
* **Cinematic Hero Section:** High-definition background video with a glassmorphism text overlay.
* **HTML Bookmarks:** Seamless navigation between sections without page reloads.
* **Responsive Layout:** Fully optimized for devices ranging from mobile phones to 4K monitors.
